# Design System: 라인가동현황 모니터링 시스템

## Overview

**Creative North Star: "도면 위의 관제반"**

모눈 위에 그린 공장 배치도(도면)에 설비 상태가 관제반 표시처럼 켜지는 화면이다. 사무실 PC에 하루 종일 띄워 두는 관제 화면이므로, 평소에는 중립 회색과 정돈된 숫자로 조용히 있다가 고장·대기·예지보전 위험이 생긴 곳만 색과 바탕으로 크게 드러난다.

밀도는 높지만 빽빽하지 않게 둔다. 숫자는 위에서 아래로 읽히게 세로로 모으고, 화면 폭 전체를 가로 띠로 채운 뒤 다시 세로선으로 나누는 구성은 쓰지 않는다. 장식은 없다. 화면의 개성은 도면(모눈 배치도), 상태 열쇠 칸, 이상 행 바탕 세 가지에서만 나온다.

**Key Characteristics:**
- 차분함 · 정확함 · 이상만 크게
- 밝은 중립 회색 바탕, 흰 표면, 강조색은 파랑 하나
- 상태 4색(R/S/I/D)은 의미 색이며 항상 코드 글자와 명칭을 같이 표시
- 핵심 숫자는 왼쪽 세로 열에 위→아래로
- 그림자·그라데이션·빛 번짐·반복 애니메이션 없음

## Colors

중립 회색 위에 의미 색 4개와 강조 파랑 하나만 쓰는 팔레트다. 모든 글자 조합은 WCAG AA를 계산해 확인했다.

### Primary
- **신호 파랑 Signal Blue** (`signal-blue`): 유일한 강조색. 생산 실적선, 달성률 막대, 키보드 포커스 테두리, 링크(제품 ID)에만 쓴다. 상태 4색과 겹치지 않는 색조로 골랐다. 흰 바탕 대비 7.46:1.

### Neutral
- **캔버스 Canvas** (`canvas`): 화면 바탕.
- **표면 Surface** (`surface`): 패널·카드·표 바탕.
- **가라앉은 표면 Surface Sunk** (`surface-sunk`): 표 행 hover, 해제된 알림 행, 선택된 목록 항목.
- **막대 홈 Track** (`track`): 가로 막대의 빈 부분.
- **먹 Ink** (`ink`): 본문과 숫자.
- **보조 먹 Ink Secondary** (`ink-secondary`): 설명·라벨.
- **흐린 먹 Ink Muted** (`ink-muted`): 메타 정보, 축 라벨. 캔버스 위 4.79:1. 정지 칸의 진한 테두리와 연결선에도 쓴다.

### State (D-77, 의미 색 · 강조색 아님)
- **가동 초록 Run** (`state-run` / 글자 `state-run-ink`): R. 꽉 찬 초록 + 흰 글자. 흰 글자 AA를 지키는 가장 밝은 초록이다(4.51:1). 이보다 밝게 하려면 글자를 진한 색으로 바꿔야 한다.
- **정지 회색 Stop** (`state-stop` / 글자 `state-stop-ink`): S. 옅은 회색 면 + 진한 회색 테두리(`ink-muted`) + 진한 글자. 초록 R과 밝기 차이(3.58:1)가 커서 색을 구분하기 어려운 사람도 가동/정지를 밝기로 구분한다. 그래프 막대에서는 진한 회색(`state-stop-solid`)을 쓴다.
- **대기 노랑 Idle** (`state-idle` / 글자 `state-idle-ink` / 테두리 `state-idle-edge`): I. 꽉 찬 노랑 + 진한 글자(10.74:1). 노랑 면은 흰 바탕과 대비가 약해(1.68:1) 진한 노랑 테두리를 1줄 둘러 칸 경계를 보이게 한다.
- **고장 빨강 Down** (`state-down` / 글자 `state-down-ink`): D. 꽉 찬 빨강 + 흰 글자(5.62:1).

### Caution (예지보전, D-77)
- **주의 노랑 테두리** (`state-idle-edge`): 예지보전 주의(80% 이상). 실선 테두리. 흰 바탕 대비 3.82:1로 비텍스트 기준 3:1을 넘는다. 주의 글자는 `caution-ink`.
- **위험 빨강 테두리** (`state-down`): 예지보전 위험(90% 이상). 점선 테두리로, 꽉 찬 빨강 고장 칸과 모양으로 구분한다.

### Tint (이상 행 바탕)
- **고장 바탕** (`down-tint`): 진행 중인 고장(D)·예지보전 위험 행.
- **대기 바탕** (`idle-tint`): 진행 중인 대기(I) 행.

### Named Rules
**The 이상만 색 Rule.** 화면에서 색 면적이 커지는 것은 진행 중인 이상(고장·대기·예지보전 위험)뿐이다. 정상·정지·해제된 항목은 바탕을 칠하지 않는다.

**The 색만으로 말하지 않기 Rule.** 상태 색은 항상 코드 글자(R/S/I/D) 또는 명칭(가동/정지/대기/고장)과 같이 나온다. 색약 사용자도 글자로 읽을 수 있어야 한다.

**The 파랑 하나 Rule.** 강조색은 신호 파랑 하나이며 실적·달성률·포커스·링크에만 쓴다. 상태를 나타내는 데 파랑을 쓰지 않는다.

## Typography

**Body Font:** Pretendard (with Malgun Gothic, system-ui)

**Character:** 한 가지 글꼴로 화면 전체를 쓴다. 위계는 크기와 색으로 만들고 굵기는 보조로만 쓴다.

### Hierarchy
- **핵심 숫자**: 요약 열의 첫 숫자(OEE, 실적/계획)가 화면에서 가장 크다. 단위(%, / 200)는 작게 붙인다.
- **보조 숫자**: 요약 열의 나머지 숫자, 상태별 대수.
- **패널 제목**: 패널마다 한 줄. 제목 옆에 흐린 글자로 범위·기준(예: "오늘 · 공정 검사")을 붙인다.
- **본문·표**: 표 셀, 목록, 설명.
- **라벨·메타**: 숫자 위 이름표, 축 라벨, 갱신 기준 시각.

구체적인 크기 단계는 `src/style.css`에서 정한다.

### Named Rules
**The 고정폭 숫자 Rule.** 모든 숫자에 `font-variant-numeric: tabular-nums`를 쓴다. 1초마다 값이 바뀌어도 자릿수가 흔들리지 않아야 한다.

**The 대문자 라벨 없음 Rule.** 라벨을 대문자·자간 넓힘으로 꾸미지 않고, 제목 위에 작은 머리글을 따로 달지 않는다.

## Layout

1920×1080 사무실 모니터 기준. 위에 고정 메뉴, 그 아래 화면마다 **같은 높이의 제목 줄**(이동 경로·탭·필터), 그 아래 본문이다.

**화면 유형별 구성**
- **대시보드**: 왼쪽 본문 = 공장 배치도(가장 큼) → 아래 생산·종합 가동률·품질 3칸. 오른쪽 세로 열 전체 = 알림. 설비 대수는 배치도 범례에 함께 적는다.
- **라인 상세**: 왼쪽 열 전체 = 라인 요약(대표 상태 → 상태별 대수 → 실적/계획 → OEE → 불량 제외). 오른쪽 위 = 라인 흐름(크게). 아래 가운데 = 시간대별 생산, 아래 오른쪽 = 라인 알림.
- **공정 상세**: 요약 숫자는 제목 줄 오른쪽. 본문 왼쪽 = 설비 카드 → 관리값 그래프. 오른쪽 열 = 비가동 이력 → 공정 검사 → 미세정지.
- **분석 화면(가동률·생산 조회·일일 리포트)**: 필터는 제목 줄. 왼쪽 세로 열 = 요약 숫자. 오른쪽 = 주 내용. 생산 조회는 제품 내역 표가 가운데 가장 큰 칸이고 라인별·시간대별은 오른쪽 열.

**배치 원칙**
- 가로로 길 필요가 없는 것은 세로로 쌓는다. 그래프·타임라인·이력 표·프레스 1~4단처럼 시간이나 순서를 가로로 보여 주는 것만 가로로 길게 둔다.
- 요약 숫자는 덩어리마다 같은 높이 칸을 차지하고, 숫자는 칸 위쪽에 붙인다.
- 한 화면 안에서 큰 칸 하나가 주인공이다(대시보드 = 배치도, 라인 상세 = 라인 흐름, 생산 조회 = 제품 내역).
- 1440×810 같은 작은 창에서는 칸 안 항목을 세로로 쌓고, 상태 단어는 숨겨도 코드 글자는 남긴다.

## Elevation & Depth

평평한 화면이다. 깊이는 캔버스 회색 → 흰 표면 → 가라앉은 표면의 단계와 가는 선으로만 만든다. 그림자는 고장 토스트처럼 화면 위에 떠야 하는 것에만 쓴다.

### Named Rules
**The 평평함 Rule.** 패널·카드·칸에 그림자를 주지 않는다. hover에 확대나 떠오름을 쓰지 않는다.

## Shapes

작게 둥근 모서리를 쓴다. 표면이 클수록 조금 더 둥글고, 칸·버튼·입력은 작게 둥글다. 패널 안쪽 요소는 패널보다 덜 둥글다. 정확한 값은 `src/style.css`에서 정한다.

## Components

### 상태 열쇠 칸 (Signature)
상태를 나타내는 기본 단위. **색 칸 안에 코드 글자(R/S/I/D)**, 칸 옆에 명칭(가동·정지·대기·고장)이나 사유를 붙인다.
- **쓰는 곳:** 범례, 설비 대수, 알림 열, 이력 표, 비가동 코드 목록, 상태 필터, 토스트.
- **색:** 위 State 색 그대로. 정지는 옅은 면 + 진한 테두리, 대기는 노랑 면 + 진한 노랑 테두리.
- **크기:** 범례·알림은 한 단계 크게, 표 안에서는 줄 높이에 맞게 한 단계 작게.
- **해제된 항목:** 같은 칸을 흐리게.

### 예지보전 표시
설비 칸이나 범례에서 **칸 바깥에 떨어진 테두리**로 표시한다. 주의 = 노랑 실선, 위험 = 빨강 점선. 설비 칸 안에는 "주의 84%"처럼 글자로 항목 비율을 붙인다. 알림 열에서는 빨강 테두리 칸 안에 "위험".

### 이상 행 바탕
알림 열, 이력 표, 공정 상세의 비가동 이력에서 **진행 중인** 고장·예지보전 위험 행은 고장 바탕, 대기 행은 대기 바탕을 깐다. 바탕을 깐 행은 글자가 색 면 가장자리에 붙지 않게 안쪽 여백을 준다.

### 설비 칸 (배치도·라인 흐름)
설비 하나 = 칸 하나. 칸 전체를 상태 색으로 칠하고, 안에 설비 이름 → (고장·대기면 비가동 코드와 사유) → 상태 코드·명칭·지속시간을 둔다. 라인 흐름처럼 칸이 클 때는 오늘 사이클·평균 CT 같은 숫자를 더 넣는다. 모눈 바탕은 배치도와 라인 흐름에만 쓴다.

### 요약 열
분석 화면과 라인 상세의 왼쪽 세로 열. 패널 제목 → 덩어리들(이름표 → 큰 숫자 → 보조 설명이나 작은 목록). 덩어리 사이는 가는 선 하나로 나눈다. 달성률처럼 목표 하나에 대한 진행은 신호 파랑 막대로 보여 준다.

### 알림 열
최근순 목록. 진행 중 위, 해제됨은 흐리게. 각 행 = 상태 열쇠 칸 → 설비 이름과 코드·사유 → 오른쪽에 시각과 지속시간. 고장 건에는 보고서 버튼.

### 탭·구간 버튼
선택된 항목은 먹색 면 + 흰 글자, 나머지는 흰 면 + 보조 글자. 묶음 전체를 가는 테두리로 감싼다.

### 표
머리줄은 흐린 작은 글자, 행 사이는 가는 선. 숫자 열은 오른쪽 정렬. 누를 수 있는 행은 hover에 가라앉은 표면.

### 고장 토스트
화면 오른쪽 아래, 먹색 바탕 + 흰 글자. 고장(D) 발생 때만 나타난다. 화면에서 그림자를 쓰는 유일한 요소.

## Do's and Don'ts

### Do:
- **Do** 상태를 표시할 때마다 색과 코드 글자(또는 명칭)를 같이 쓴다.
- **Do** 진행 중인 이상만 색 면이나 바탕으로 키운다.
- **Do** 모든 색·간격·글꼴·둥글기를 `src/style.css`의 `:root` 변수로 두고, 컴포넌트는 변수만 쓴다.
- **Do** 숫자는 tabular-nums로 두고, 값이 바뀌어도 레이아웃이 흔들리지 않게 한다.
- **Do** 빈 값은 숫자 "-", 그래프·목록 "데이터 없음"으로 표시한다 (D-78).
- **Do** 요약 숫자를 세로 열에 위→아래로 모은다.
- **Do** 움직임은 고장 토스트와 배치도의 물류 점(D-81)에만 쓴다.

### Don't:
- **Don't** 화면 폭 전체를 가로 띠로 채운 뒤 다시 세로선으로 나누지 않는다.
- **Don't** 상태를 작은 점·표시등만으로 나타내지 않는다. 눈에 잘 띄지 않는다.
- **Don't** 정상(R)·정지(S)·해제된 행에 바탕색을 칠하지 않는다.
- **Don't** 그라데이션, 빛 번짐(glow), 반복 애니메이션, 카드 hover 확대, 장식 이미지를 쓰지 않는다.
- **Don't** 1초 갱신마다 깜빡이는 효과를 주지 않는다.
- **Don't** 강조 파랑을 상태 표시에 쓰거나, 상태 4색을 강조 목적으로 쓰지 않는다.
- **Don't** 시안 B(`wireframes/후보/`)의 px 수치를 구현에 그대로 옮기지 않는다. 시안은 구성 확인용이다.
