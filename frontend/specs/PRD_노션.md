### 1. 배경 및 목표 (Background & Objectives)

- **배경 (Background):**
    - 24시간 가동, 교대 구분 없음
    - [현장] 차체 부품 생산 공장 (상우하이택), 제품 = 차체 부품 1개
    - 공정 A~F: 코일 입고 → 슬리팅 → 프레스 → 용접 → 도장 → 출고
    - 설비 39대: 슬리팅 6 · 프레스 24 · 용접로봇 6 · 도장라인 2 · 비전검사기 1(출고). 코일 입고는 설비 없이 수량만 관리
    - 라인 L1~L6: 각각 슬리팅 1 → 프레스 4단(직렬) → 용접 1. 6개 라인 제품이 도장 라인(도장 2대)으로 모였다가 출고
    - 공정마다 끝난 제품을 검사해 불량은 그 자리에서 제외
- **문제 정의 (As-is):**
    - 현재 가동 상황을 현장에 가야만 확인할 수 있음
    - 설비가 왜 멈췄는지 확인하는 데 시간 소요
    - 공장·라인 생산량과 제품별 이력을 한눈에 파악하기 어려움
    - 어느 공정에서 불량이 나는지 알기 어려움
    - 설비 고장 시 생산계획 변경에 시간 소요
    - 알람이 뜨지 않는 짧은 정지(미세정지)는 기록조차 되지 않음
- **목표 (To-be):**
    - 설비 가동·정지 상태를 한 화면에서 실시간 확인
    - 정지 원인(고장·재공부족·작업지연·안전문제 등)을 자동으로 구분해 표시
    - 공장·라인 목표 대비 실적과 종합 가동률(OEE)을 실시간 확인, 제품별 이력 조회
    - 공정별 불량을 기록해 품질 문제 공정을 바로 확인
    - 고장 시 다른 라인의 여력으로 재배정안과 계획수정 보고서를 버튼 한 번으로 작성
    - 관리값 추세로 고장 위험을 미리 표시 (예지보전)
- **기대효과:**
    - 빠른 이상 발견·대응, 불필요한 대기시간 감소
    - 목표 달성 여부 즉시 확인, 생산 손실 최소화, 납기 지연 예방
    - 보이지 않던 미세정지 손실 가시화

### 2. 타겟 사용자 (Target Audience)

- **공정 관리자:** 사무실 PC에서 대시보드로 실시간 이상 여부를 모니터링하고, 가동률과 생산 실적을 확인하며, 고장 시 재배정 보고서를 받아 생산계획을 조정하는 사용자.
- 로그인한 사용자는 모두 같은 화면과 권한을 가진다. 작업자 입력은 최소화한다.

**0. 공통 기능**

- **0.1. 로그인 [필수]**
    - 아이디·비밀번호로 로그인해야 모든 화면을 볼 수 있음.
    - 로그인하지 않고 다른 화면에 들어오면 로그인 화면으로 이동, 로그인 후 원래 화면으로 복귀.
    - 계정은 미리 등록하며 회원가입 화면은 없음.
    - 모든 사용자는 같은 권한.
    - 자동 로그아웃 없음. 브라우저를 닫아도 7일간 로그인 유지 (모니터에 상시 띄워두는 용도).
    - 로그인 실패 시 메시지만 표시, 계정 잠금 없음.
- **0.2. 화면 구성 [필수]**
    - 메뉴: 대시보드 / 생산 / 가동률 / 예지보전 / 알람·비가동 이력 / 리포트 / 설정.
    - 화면 단계 3개: 대시보드 → 라인 상세 → 공정 상세. 도장도 같은 3단계. 3D 공장은 대시보드 안에서 전환.
    - 사무실 PC 모니터(1920×1080) 기준. [가정]
- **0.3. 라인 구성 [필수]**
    - 공장 1개 > 라인 > 공정 > 설비. 라인 = L1~L6(슬리팅·프레스 4단·용접)과 도장 라인. 입고·출고는 공용 구역.
    - 헤더에 라인 선택은 두지 않고, 라인은 화면 안에서 고름.
    - 설비 이름은 라인을 붙여 표시 (예: L3 프레스 2단, 도장 #1).
- **0.4. 실시간 갱신 [필수]**
    - 실시간 값은 1초마다 갱신.
    - 상태 색: 가동 초록, 정지 회색, 대기 노랑, 고장 빨강. 예지보전 주의는 노랑 테두리, 위험은 빨강 테두리.
    - 값이 없으면 숫자는 "-", 그래프·목록은 "데이터 없음".
- **0.5. 화면 알림 [필수]**
    - 설비가 고장(D) 상태가 되면 화면 우하단에 팝업(토스트) 표시.
    - 헤더 알림 아이콘에 개수 표시, 누르면 최근 알림 5건과 "전체 보기".

**1. 대시보드**

**목적: 라인 전체의 현재 상태, 생산 실적, 이상 발생 위치를 즉시 파악한다.**

- **1.1. 공장 배치도**
    - **1.1.1. 설비 칸 배치 [필수]**
        - 설비 하나를 칸 하나로 그림: 입고 1칸 → 라인 6줄(슬리팅 1 · 프레스 4 · 용접 1) → 도장 2칸 → 비전 1칸(출고). 도장 2칸은 각각 따로 칸을 두고, 비전 1칸으로 합류.
        - 칸 색은 설비 상태 (가동 초록 · 정지 회색 · 대기 노랑 · 고장 빨강). 칸 안에 비가동 코드, 고장이면 지속시간.
        - 라인 줄 끝에 오늘 라인 실적 / 라인 계획. [가정]
        - 코일 입고는 상태 색 없이 오늘 입고 코일 수와 슬리팅 앞 재고만 표시. 입고 수량은 시뮬레이터가 생성.
    - **1.1.2. 연결선과 물류 흐름 [필수]**
        - 입고에서 6갈래로 나뉘어 각 라인을 지나 도장 2대로 모이고 출고로 가는 선을 그림.
        - 제품이 다음 설비로 넘어갈 때마다 점이 선을 따라 이동 (실제 생산 이벤트 기준). 공정 검사 불량이면 그 자리에서 점이 사라짐. [가정]
    - **1.1.3. 라인 상세 이동 [필수]**
        - 라인 줄이나 도장 칸을 누르면 라인 상세(2.1)로 이동. 입고·비전 칸은 바로 공정 상세로. [가정]
    - **1.1.4. 2D ↔ 3D 전환 [필수]**
        - 배치도 영역을 3D 공장 화면으로 바꿔 볼 수 있음 (5장).
- **1.2. 오늘 생산 [필수]**
    - 공장 목표, 실적(출고 양품 수), 달성률 표시.
    - 시간대별 누적 실적과 목표선 그래프. 목표선 = 목표 × 지난 부하시간 비율. [가정]
    - 오늘 목표가 없으면 "목표 미설정"과 목표 입력 화면 바로가기 표시.
    - 칸을 누르면 생산 조회(10장)로 이동, 기간 = 오늘.
- **1.3. 종합 가동률 [필수]**
    - OEE 큰 숫자 1개와 시간·속도 가동률, 양품률 3개 표시.
- **1.4. 품질 [필수]**
    - 공정별 오늘 불량 수(슬리팅·프레스·용접·도장)와 출고 비전검사 양품·불량 수·불량률, 원형 그래프. [가정]
- **1.5. 알림 열 [필수]**
    - 화면 오른쪽 세로 열 전체를 알림 칸으로 사용. 오늘 알림 전체를 최근순으로 표시하고 넘치면 스크롤.
    - 헤더 알림 아이콘은 다른 화면을 위해 그대로 둠.
    - 진행 중인 알림을 위에, 해제된 알림은 흐리게.
    - 누르면 해당 공정 상세로 이동. 고장 건은 계획수정 보고서 바로가기.

**2. 라인 상세 · 공정 상세**

**목적: 대시보드 → 라인 → 공정 순서로 들어가며 멈춘 곳과 원인을 찾는다.**

- **2.1. 라인 상세 [필수]**
    - 라인 탭(L1~L6, 도장)으로 라인 전환.
    - 요약: 라인 대표 상태와 상태별 설비 대수, 오늘 라인 실적 / 라인 계획 / 달성률, 라인 OEE, 오늘 불량 제외 수.
    - 라인 흐름: 슬리팅 → 프레스 1~4단 → 용접 (도장 라인은 도장 2대) 설비 칸과 물류 점. 공정 사이에 재공·생산·불량 수.
    - 시간대별 라인 계획선 vs 누적 실적 그래프, 이 라인의 오늘 알림.
    - 공정이나 설비를 누르면 공정 상세로 이동.
- **2.2. 공정 요약 [필수]**
    - 상태별 설비 대수, 오늘 생산·양품, 공정 OEE, 앞·뒤 재공품.
    - 공정 탭(그 라인의 슬리팅 / 프레스 / 용접, 도장 라인은 도장)으로 바로 이동.
- **2.3. 설비 목록 [필수]**
    - 설비마다 상태, 비가동 코드, 현재 상태 지속시간 표시. 번호순 고정 (프레스는 1~4단).
    - 설비를 누르면 아래 그래프와 이력이 그 설비로 바뀜.
- **2.4. 관리값 추이 [필수]**
    - 선택 설비의 관리값을 선 그래프로 표시하고 상·하한선을 함께 그림.
    - 공정별 관리값: 슬리팅 전류·주파수·토크 / 프레스 압력·프레스 시간 / 용접 가압력·전류·전압·통전시간 / 도장 pH·온도·전류·전압.
- **2.5. 비가동 이력과 조치 메모 [필수]**
    - 선택 설비의 오늘 비가동 이력 표시.
    - 정지 사유는 자동 표시만 함. 조치 메모 한 줄만 선택 입력, 저장한 사용자가 조치 담당자로 기록.
- **2.6. 공정 검사 [필수]**
    - 오늘 검사 수·불량 수·불량률과 불량 목록(시각, 제품 ID, 설비, 사유).
    - 제품 ID를 누르면 생산 조회의 그 제품 이력으로 이동.
- **2.7. 미세정지 [차순위]**
    - 설비별 미세정지 건수, 손실시간, 사이클타임 분포.
- **2.8. 공정별 상세 화면 [필수]**
    - 2.2~2.7을 공통 틀로 하고 공정마다 화면을 따로 둠.
        - 2-1 코일 입고: 오늘 입고 기록, 슬리팅 앞 재고 추이, 오늘 투입 수. 설비·관리값 없음.
        - 2-2 슬리팅: 설비 1대(실설비/시뮬레이터 표시), 전류·토크·DC 전압, 지령 vs 출력 주파수, 인버터 트립, 환산 생산량.
        - 2-3 프레스: 1~4단 설비를 순서대로, 압력·프레스 시간, 단별 사이클 수·평균 사이클타임, 4단 후 검사.
        - 2-4 용접: 설비 1대, 가압력·전류·전압·통전시간.
        - 2-5 도장: 도장 2대, pH·온도·전류·전압·건조로 온도, 라인별로 받은 수. [가정]
        - 2-6 출고: 비전 1대 상태·검사 수·불량 수, 오늘 출고 불량 목록. 그래프 없음.

**3. 가동률**

**목적: 얼마나 가동했고, 무엇 때문에 얼마나 손실이 났는지 확인한다.**

- **3.1. 조회 조건 [필수]**
    - 기간 [일 / 주 / 월], 날짜, 라인, 공정, 설비 선택. 기본은 오늘, 전체.
    - 주·월은 기간 전체를 합산한 OEE와 일별 OEE 추이 선 그래프를 표시.
    - 다운로드는 지금 범위에 없음.
- **3.2. 종합 가동률 (OEE) [필수]**
    - OEE와 3요소를 함께 표시.
        - 부하시간 = 대상 시간(지난날은 24시간, 오늘은 자정부터 지금까지) − 계획정지(S) 시간
        - 시간 가동률 = (부하시간 − 대기·고장 시간) ÷ 부하시간
        - 속도 가동률 = 표준 사이클타임 × 생산수량 ÷ 가동시간 (미세정지 손실이 여기서 드러남)
        - 양품률 = 양품 ÷ 생산 (공정은 공정 검사 결과, 라인·공장은 출고 양품 ÷ 슬리팅 투입) [가정]
        - OEE = 시간 가동률 × 속도 가동률 × 양품률
    - 24시간 가동. 하루 집계는 자정 기준 00:00~24:00. [가정]
    - 자정 직후나 하루 전체가 계획정지라 부하시간이 0이면 "-" 표시.
- **3.3. 라인별·공정별 비교 [필수]**
    - 라인 전체를 보면 라인별(L1~L6, 도장, 출고) OEE 막대, 라인을 고르면 그 라인의 공정별 막대와 3요소. [가정]
    - 설비가 없는 코일 입고는 제외.
- **3.4. 비가동 코드별 분석 [필수]**
    - 비가동 코드별 시간과 건수 (계획정지·셋업·재공부족·작업지연·장비고장·알람·안전문제).
    - 계획정지·셋업은 손실이 아니므로 회색으로 구분하고, 손실(대기·고장)만 색으로 표시.
- **3.5. 상태 타임라인 [필수]**
    - 00:00~24:00 시간축에 라인·공정 또는 설비별 R/S/I/D 구간을 색 띠로 표시.

**4. 예지보전**

**목적: 관리값이 기준에 가까워지는 설비를 미리 찾아 고장 전에 대응한다.**

- **4.1. 설비 위험도 목록 [필수]**
    - 최근 10분 평균값이 정상 범위 가운데에서 상한(또는 하한)까지 간 정도를 %로 계산.
    - 관리값이 여러 개인 설비는 가장 높은 항목을 설비 위험도로 쓰고 항목명을 같이 표시 (예: 전류 84%).
    - 80% 이상 주의, 90% 이상 위험. 관리값이 있는 설비 38대를 위험한 순서로 정렬하고 정상 설비는 접어둠. 설비 이름에 라인 표시.
    - 위험이 되면 대시보드 알림 열에만 표시. 이메일·슬랙은 보내지 않음.
    - 규칙 기반이며 AI 모델은 쓰지 않음.
- **4.2. 관리값 추이 [필수]**
    - 선택 설비의 관리값 그래프. 상·하한선과 80%·90%선 표시.
- **4.3. 상한 도달 예상 시간 [차순위]**
    - 값이 변하는 속도로 "이대로면 약 N시간 뒤 상한 도달" 표시.
- **4.4. 정비 이력 [확장]**
    - 설비 정비 내역 기록과 표시.

**5. 3D 공장**

**목적: 공장 배치 위에서 설비 상태를 직관적으로 본다.**

- **5.1. 3D 상태 표시 [필수]**
    - 대시보드 공정 흐름 영역에서 전환. 별도 메뉴 없음.
    - 3D 공장 모델의 설비 색으로 R/S/I/D 상태 표시, 1초 갱신.
    - 회전·확대, 공정으로 이동.
- **5.2. 알람 패널 [필수]**
    - 현재 고장(D) 상태인 설비 목록.
- **5.3. 설비 정보 패널 [필수]**
    - 설비를 누르면 설비 ID, 상태, 비가동 코드, 관리값 현재값, 공정 상세 바로가기.

**6. 알람·비가동 이력**

**목적: 언제, 어디서, 왜, 얼마나 멈췄는지 자동으로 남기고 관리자에게 알린다.**

- **6.1. 상태·정지 원인 자동 판정 [필수]**
    - 위에서부터 먼저 맞는 규칙 하나만 적용.
        1. 안전 펜스 개방, 비상정지 → 고장(D) / 안전문제
        2. 설비 이상 신호(인버터 트립 등) → 고장(D) / 장비고장
        3. 관리값이 상·하한 이탈 → 고장(D) / 장비고장(알람)
        4. 계획정지 시간대(예방보전, 금형 교체, 코일·나이프 교체) → 정지(S) / 계획정지·셋업
        5. 앞 공정이 멈췄고 들어올 재공이 없음 → 대기(I) / 재공부족
        6. 뒤 공정이 막혀 내보낼 곳이 없음 → 대기(I) / 작업지연
        7. 생산 중 → 가동(R)
    - 작업자 부재·투입지연은 다루지 않음. 설비와의 통신 끊김은 없다고 가정.
- **6.2. 비가동 자동 기록 [필수]**
    - 가동(R)이 아닌 구간마다 1건 자동 기록: 시작, 종료, 설비, 상태, 비가동 코드, 상세, 지속시간.
    - 끝나기 전에는 "진행 중"으로 표시하고 경과 시간 갱신.
- **6.3. 외부 알림 발송 [필수]**
    - 고장(D) 상태가 되면 이메일(1순위), 이어서 슬랙(2순위)으로 발송.
    - 내용: 설비, 상태, 비가동 코드, 상세, 발생 시각, 화면 링크.
    - 같은 설비의 같은 알람은 해제 전까지 다시 보내지 않음.
    - 발송에 실패해도 화면 알림은 유지하고 실패를 기록.
    - 받는 사람과 슬랙 주소는 설정 파일 고정값.
- **6.4. 이력 조회 [필수]**
    - 필터 순서: 기간 → 라인 → 공정 → 상태 → 비가동 코드 → "진행 중만". 기본은 오늘, 전체 라인, 고장(D)·대기(I)만. 계획정지(S)는 선택하면 표시.
    - 한 번에 최대 31일, 50건씩 페이지.
    - 표: 발생, 해제, 라인, 설비, 상태, 비가동 코드, 상세, 지속, 발송(메일·슬랙 성공/실패), 조치 메모, 조치 담당자, 보고서.
    - 조치 메모는 건마다 한 줄, 선택 입력, 수정 가능. 조치 담당자는 메모를 저장한 로그인 사용자 이름으로 자동 기록.
- **6.5. 예지보전 위험 이력 [필수]**
    - 같은 화면의 별도 탭. 위험(90%)이 된 설비·항목·%·발생·해제 시각을 기록.

**7. 리포트**

**목적: 하루 생산 결과와 고장 시 계획 변경안을 문서로 확인한다.**

- **7.1. 일일 생산 리포트 [필수]**
    - 하루 요약: 라인별 실적·계획, 공정별 생산량·불량 수, 비가동 코드별 시간·건수, OEE 요약.
    - 재공품 현황: 공정 사이마다 "앞 공정 양품 − 뒤 공정 투입량".
    - 제품별 상세는 생산 조회(10장).
    - 화면 조회만. PDF 없음.
- **7.2. 생산 재배정·계획수정 보고서 [필수]**
    - 자동으로 만들지 않음. 고장(D) 건에서 [보고서 만들기]를 누르면 그 시점 기준으로 계산해 작성.
    - 재배정은 제안만 하고 목표·설비 계획을 실제로 바꾸지 않음.
    - 계산 규칙 (정해진 규칙, AI 미사용):
        1. 라인 안 설비가 고장 나면 직렬이라 그 라인 전체가 멈춘 것으로 봄. 부족 수량 = 그 라인이 오늘 남은 시간(자정까지) 동안 만들 예정이던 라인 계획 수량
        2. 다른 정상 라인별 남은 능력 = 남은 시간 ÷ 라인 사이클타임 − 남은 라인 계획
        3. 부족 수량을 남은 능력 비율대로 나눠 배정
        4. 남은 능력 합이 모자라면 "목표 미달 예상 ○개" 표시
        5. 도장 설비 고장은 같은 공정의 다른 1대로 같은 계산. 비전은 1대라 대체 없이 출고 전량 미달 예상으로 표시 [가정]
    - 정상 라인이 없으면 전량을 미달 예상으로 표시.
    - 내용: 발생 라인·설비·시각·원인, 부족 수량, 라인별 추가 배정 표, 결과.
    - 날짜별 보고서 목록에서 골라 보기. 화면 조회 + PDF 다운로드.

**8. 설정**

**목적: 사람이 정해야 하는 기준값만 입력한다.**

- **8.1. 생산 목표 [필수]**
    - 날짜별 공장 목표 수량 입력 (하루 1건, 공장 전체 1개). 같은 날짜는 덮어씀.
    - 라인 계획 = 목표 ÷ 가동 라인 수로 자동 배분해 표시. 라인별 입력은 없음. 도장 라인 계획은 목표 전체.
    - 오늘과 앞으로의 날짜만 입력·수정. 지난 날짜는 잠금.
    - 목표를 넣지 않은 날은 전날 값을 쓰지 않고 "목표 미설정"으로 표시.
    - 최근 목표와 날짜별 달성률 목록.
- **8.2. 관리값 기준 [필수]**
    - 설비 종류별 관리값 상·하한을 화면에서 변경.
    - 저장 즉시 상태 판정(6.1의 3번)과 예지보전 위험도에 반영.
    - 처음 값은 데이터셋 설명서의 정상 범위 (예: 프레스 압력 200~350, 압력 합계 400~700).
    - 하한이 상한보다 크면 저장하지 않고 오류 표시.
    - 항목마다 마지막으로 바꾼 시각과 사람 표시. 변경 이력 목록은 없음.
- **8.3. 계획정지 일정 입력 [확장]**
    - 지금은 시뮬레이터가 계획정지 일정을 만들고 화면 입력은 없음.
- **8.4. 알림 수신자 관리 [확장]**
    - 이메일·슬랙 받는 사람을 화면에서 등록.

**9. 데이터 수집**

**목적: 실설비와 데이터셋을 실시간 설비 데이터처럼 모아 저장한다.**

- **9.1. 공정별 데이터 출처 [필수]**

| 공정 | 출처 |
| --- | --- |
| A 코일 입고 | 시뮬레이터 생성 (수량만) |
| B 슬리팅 | 1대는 실설비 LS iG5A 인버터, 5대는 시뮬레이터 |
| C 프레스 | KAMP 프레스 데이터 (1대분을 24대로 복제) |
| D 용접 | KAMP 용접 데이터 (1대분을 6대로 복제) |
| E 도장 | KAMP 도금욕 데이터를 전착도장 수조 값으로 사용. 건조로 온도는 생성 |
| F 출고 | KAMP 머신비전 데이터 (양품/불량) |

- **9.2. 실설비 수집 [필수]**
    - iG5A 인버터를 RS-485 Modbus RTU로 읽음 (읽기만, 설비 제어 안 함).
    - 읽는 값: 운전 상태, 트립 정보, 출력 전류·주파수·전압·토크, RPM.
    - 운전 중 → 가동(R), 트립 → 고장(D)/장비고장, 비상정지 → 고장(D)/안전문제.
    - 인버터는 생산수량을 주지 않으므로 운전시간 × 속도로 환산.
- **9.3. 데이터 시뮬레이터 [필수]**
    - 데이터셋 행을 사이클마다 하나씩 재생하고 현재 시각을 붙임.
    - 1대분 데이터를 노이즈·오프셋으로 복제해 설비 대수를 맞춤.
    - 슬리팅 투입 때 제품 ID를 발급하고, 제품이 라인 설비를 차례로 거쳐 비어 있는 도장 설비 → 출고로 가게 함.
    - 공정(슬리팅·프레스 4단 후·용접·도장) 끝에서 검사 판정: 그 사이클 관리값이 기준을 벗어났으면 불량, 아니면 기본 불량률 0.5%로 무작위. 불량은 바로 제외(폐기, 재작업 없음). [가정]
    - 공정 사이 버퍼를 흉내 내 재공부족·작업지연이 생기게 함.
    - 계획정지 일정을 만들어 백엔드와 공유하고, 고장·관리값 이탈·미세정지 시나리오를 넣음.
    - 특정 설비에 고장을 즉시 넣을 수 있음 (명령으로 실행).
- **9.4. 전송·저장 [필수]**
    - 인버터 → Modbus → Node-RED, 시뮬레이터 → OPC UA → Node-RED.
    - Node-RED → MQTT → 백엔드 → PostgreSQL.
- **9.5. 미세정지 감지 [차순위]**
    - 가동 중인데 실제 사이클타임이 표준의 1.5배를 넘으면 미세정지 1건.
    - 슬리팅은 출력 주파수가 지령 주파수보다 일정 비율 이상 낮은 구간.
    - 손실시간 = 실제 − 표준. 속도 가동률에 반영.

**10. 생산 조회**

**목적: 만든 제품 하나하나의 이력과 기간·라인별 생산량을 계획과 비교한다.**

- **10.1. 진입 [필수]**
    - 메뉴 "생산", 또는 대시보드 "오늘 생산" 칸 클릭(기간 = 오늘).
- **10.2. 조회 조건 [필수]**
    - 기간 [일 / 주 / 월] 또는 날짜 범위(최대 31일) [가정], 라인(전체 / L1~L6), 결과(전체 / 양품 출고 / 불량 제외 / 진행 중), 제품 ID 검색.
- **10.3. 계획 대비 생산량 [필수]**
    - 요약: 계획, 실적(출고 양품), 달성률, 투입, 불량 제외(공정별).
    - 라인별 계획 대비 막대 (L1~L6).
    - 일 조회는 시간대별 누적 실적 vs 계획선, 주·월 조회는 일별 실적 vs 계획.
- **10.4. 제품 내역 [필수]**
    - 제품 ID, 라인, 투입 시각, 완료 시각, 거친 공정, 결과(양품 / 어느 공정에서 불량 제외 / 진행 중). 최근순 50건씩.
    - 제품을 펼치면 공정별 설비, 통과 시각, 검사 판정, 불량 사유.
    - 제품 단위 기록은 90일 보관. 그보다 지난 기간은 수량 집계만 표시.
