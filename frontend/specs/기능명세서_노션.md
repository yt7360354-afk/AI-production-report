## 1. 제품 요구사항

### 1.1 배경
- 대상 현장: 차체 부품 생산 공장(상우하이택). 공정 A~F = 코일입고 → 슬리팅 → 프레스 → 용접 → 도장 → 출고.
- 설비 39대: 슬리팅 6, 프레스 24, 용접로봇 6, 도장라인 2, 비전검사기 1(출고). 코일입고는 설비 없이 수량만 본다.
- 라인 구성:

| 구분 | 구성 | 설비 |
|---|---|---|
| 코일입고 (공용) | 설비 없음, 수량만 | - |
| 라인 L1~L6 | 슬리팅 1 → 프레스 4단(직렬) → 용접 1 | 라인당 6대, 합 36대 |
| 도장 라인 | 도장 공정 1개. L1~L6 제품을 비어 있는 도장 설비가 받음 | 2대 |
| 출고 (공용) | 비전검사기로 최종 검사 | 1대 |

### 1.2 문제와 목표
| # | AS-IS (문제) | TO-BE (시스템) | 기대효과 |
|---|---|---|---|
| 01 실시간 상태 | 현재 가동 상황을 현장에 가야 확인 가능 | 설비 가동·정지 상태와 물류 흐름을 공장 배치도에서 실시간 확인 | 빠른 이상 발견·대응 |
| 02 정지 원인 | 설비가 왜 멈췄는지 확인에 시간 소요 | 고장·재공부족·작업지연·안전문제 등 원인을 자동 구분 표시 | 불필요한 대기시간 감소 |
| 03 생산 실적 | 생산량을 한눈에 파악하기 어려움 | 공장·라인 목표 vs 실적, OEE 실시간 비교, 제품별 이력 조회 | 목표 달성 여부 즉시 확인 |
| 04 생산 재배정 | 고장 시 생산계획 변경에 시간 소요 | 다른 라인의 여력으로 재배정안과 보고서를 버튼 한 번으로 작성 | 생산 손실 최소화, 납기 지연 예방 |
| 05 숨은 손실 | 알람이 안 뜨는 미세정지가 기록되지 않음 | 사이클타임 편차로 미세정지 검출, 속도 가동률에 반영 | 보이지 않던 손실 가시화 |
| 06 품질 | 어느 공정에서 불량이 나는지 알기 어려움 | 공정마다 검사해 불량은 바로 제외하고 공정별로 기록 | 불량 공정 조기 파악 |

### 1.3 사용자와 사용 환경
- 사용자: 로그인한 사용자. 모두 같은 권한, 역할 구분 없음. 계정은 미리 등록하고 회원가입은 없음.
- 작업자 입력은 최소화한다. 사람이 입력하는 것은 생산 목표, 관리값 기준, 조치 메모(선택)뿐이다.
- 사용 환경: 사무실 PC 모니터, 1920×1080 기준 [가정]. 실시간 화면 1초 갱신.

### 1.4 범위
| 구분 | 내용 |
|---|---|
| 포함 | 4장 기능 목록의 FN-001 ~ FN-018 |
| 제외 | 설비 제어(읽기만 함), 작업자 이슈(부재·투입지연), 통신 두절 처리, 교대 근무, 불량 재작업 [가정] |
| 확장 예정 | 작업자 이슈, 알림 수신자 관리 화면, 정비 이력 |

### 1.5 전제
- 계층: 공장 1개 > 라인 > 공정 > 설비. 라인 L1~L6은 공정 B~D가 직렬, 도장 라인은 공정 E 하나.
- 제품 = 차체 부품 1개. 슬리팅 투입 때 제품 ID를 발급하고 라인이 정해진다.
- 24시간 가동, 교대 구분 없음. 하루 집계는 자정 기준 00:00~24:00 [가정].
- 목표는 하루 단위 공장 전체 1개. 라인 계획 = 하루 목표 ÷ 가동 라인 수.

## 2. 시스템 구성
```
[슬리터 iG5A 인버터] --RS-485 Modbus RTU--> Node-RED ┐
[KAMP 데이터셋] --> 데이터 시뮬레이터 --OPC UA-->  Node-RED ┼--MQTT--> 백엔드 --> PostgreSQL
                                                          ┘            │
                                         이메일 · 슬랙  <---------------┤
                                         Vue 프론트 (1초 갱신) <--------┘
```
| 공정 | 데이터 출처 |
|---|---|
| A 코일입고 | 시뮬레이터 생성 (수량만) |
| B 슬리팅 | 1대 실설비 iG5A 인버터, 5대 시뮬레이터 |
| C 프레스 | KAMP Press (Press-01 1대분을 24대로 복제) |
| D 용접 | KAMP Welding (Spot-01 1대분을 6대로 복제) |
| E 도장 | KAMP 도금욕 → 전착도장 수조로 간주. 건조로 온도는 생성 |
| F 출고 | KAMP Machinevision (양품/불량 라벨) |
| 공정 검사 (B~E) | 시뮬레이터 생성 [가정] |

## 3. 공통 규칙

### 3.1 설비 상태 RSID
| 상태 | 뜻 | 비가동 코드 |
|---|---|---|
| R | 가동 | - |
| S | 정지 (계획) | 계획정지, 계획정지(셋업) |
| I | 대기 | 재공부족, 작업지연(뒤 공정 막힘) |
| D | 고장·알람 | 장비고장, 장비고장(알람), 안전문제 |

상황별 비가동 코드:

| 상황 | 상태 | 비가동 코드 |
|---|---|---|
| 정상 생산 중 | R | - |
| 예방보전, 모델(금형) 교체 | S | 계획정지 |
| 슬리팅 코일 교체·나이프 교체 | S | 계획정지(셋업) |
| 앞 설비가 멈춰 소재가 안 들어옴 (예: 슬리터 고장 → 프레스 대기) | I | 재공부족 |
| 뒤 설비가 막혀 내보낼 곳이 없음 (예: 도장 정지 → 용접 대기) | I | 작업지연 |
| 설비 고장 (유압 펌프, 컨베이어, 카메라 연결 끊김) | D | 장비고장 |
| 공정 값 기준 이탈 (프레스 압력 상한, 용접 전류, 건조로 온도) | D | 장비고장(알람) |
| 안전 펜스 개방, 비상정지 | D | 안전문제 |

- 판정 순서: FN-002
- 대표 상태: 공정·라인 안 설비 중 가장 나쁜 상태, D > I > S > R

### 3.2 시간과 집계
- 집계 기준일: 00:00 ~ 24:00, 24시간 가동 [가정: 자정 기준]
- 실시간 값: 1초 갱신
- 집계 단위: 설비 → 공정 → 라인 → 공장

### 3.3 가동률 산식
| 지표 | 산식 |
|---|---|
| 부하시간 | 대상 시간(지난날은 24시간, 오늘은 자정부터 지금까지) − S 시간 |
| 시간가동률 | (부하시간 − I·D 시간) / 부하시간 |
| 성능가동률 | 표준CT × 생산수량 / 가동시간 |
| 양품률 | 설비·공정: 공정 검사 양품 / 생산. 라인·공장: 출고 양품 / 슬리팅 투입 [가정] |
| OEE | 시간가동률 × 성능가동률 × 양품률 |

### 3.4 생산 수량 정의
| 수량 | 정의 |
|---|---|
| 투입 | 슬리팅에 들어가 제품 ID를 받은 수 |
| 공정 생산 | 그 공정을 끝낸 수 (불량 포함) [가정] |
| 공정 양품 / 불량 | 공정 검사 결과. 불량은 제외되어 다음 공정에 가지 않음 |
| 공장 실적 | 오늘 출고 양품 수 |
| 라인 실적 | 그 라인에서 투입된 제품의 출고 양품 수. 도장 라인은 도장 양품 수 [가정] |
| 라인 계획 | 하루 목표 ÷ 가동 라인 수(그날 하루 전체가 계획정지인 라인 제외) [가정]. 도장 라인은 하루 목표 전체 |

## 5. 기능 상세

### FN-001 실시간 공장 모니터링
- 입력: MQTT로 들어오는 설비 데이터 (상태 신호, 관리값, 사이클 완료, 검사 결과)
- 처리:
  1. 설비마다 FN-002로 RSID와 비가동 코드, 현재 상태 지속시간을 계산
  2. 공정·라인마다 R·S·I·D별 설비 대수와 대표 상태(3.1)를 계산
  3. 제품이 공정을 옮겨 갈 때마다 이동 이벤트(제품 ID, 출발 설비, 도착 설비)를 만듦 → 화면의 물류 점
  4. 1초마다 화면에 전달
- 출력: 공장 배치도(설비 칸 40개 + 입고, 연결선, 물류 점), 라인·공정 상세의 설비 목록, 상태 지속시간
- 예외: 코일입고(A)는 설비가 없어 상태 없이 오늘 입고 코일 수와 슬리팅 앞 재고만 표시. 입고 수량은 시뮬레이터 생성

### FN-002 상태·정지 원인 자동 판정
- 입력: 설비 상태 신호, 관리값, 앞뒤 설비 상태와 재공, 계획정지 일정, 시뮬레이터 이벤트
- 판정 규칙 (위에서부터 먼저 맞는 규칙 하나만 적용):
  1. 안전 신호(펜스 개방, 비상정지 / iG5A EST(BX)) → D / 안전문제
  2. 설비 이상 신호(iG5A Fault Trip 등) → D / 장비고장
  3. 관리값이 상·하한 이탈 (FN-015 기준) → D / 장비고장(알람)
  4. 계획정지 시간대(예방보전, 금형교체, 코일·나이프 교체) → S / 계획정지 또는 계획정지(셋업)
  5. 앞 설비가 R이 아니고 투입 재공이 0 → I / 재공부족 (라인 안 직렬이므로 프레스 2단의 앞 설비는 프레스 1단)
  6. 뒤 설비가 R이 아니고 배출 버퍼가 가득 참 → I / 작업지연
  7. 생산 중 → R
- 출력: 설비별 현재 상태·코드·상세(트립명 등)·시작 시각. 상태가 바뀌면 FN-005, FN-006에 전달
- 제외: 작업자 부재·투입지연, 통신 두절

### FN-003 생산 현황
- 입력: 공정별 사이클 완료 수, 공정 검사 결과(FN-017), 출고 비전검사 결과(FN-013), 오늘 목표(FN-014)
- 처리 (수량 정의는 3.4):
  - 공장 실적 = 오늘 출고 양품 수 누적, 달성률 = 공장 실적 / 목표
  - 라인 실적·라인 계획·라인 달성률
  - 공정별 생산량 = 오늘 사이클 완료 수, 양품 수. 슬리팅 실설비는 운전시간 × 속도로 환산
  - 시간대별 목표선 = 목표 × (경과 부하시간 / 전체 부하시간) [가정]. 라인은 라인 계획으로 같은 방식
- 출력: 목표·실적·달성률, 시간대별 누적 실적과 목표선, 라인별·공정별 생산량
- 예외: 오늘 목표가 없으면 달성률 대신 "목표 미설정"과 SCR-008 바로가기 표시

### FN-004 설비 가동률 (OEE)
- 입력: FN-002 상태 이력, FN-003 생산량, FN-017·FN-013 양품 수, 설비별 표준CT
- 처리: 3.3 산식으로 설비 → 공정 → 라인 → 공장 순서로 집계. 기간은 일 / 주 / 월. 주·월은 기간 전체 시간을 합산해 계산
- 출력:
  - OEE 큰 숫자 1개와 시간·성능·양품률 3개
  - 라인별 OEE (L1~L6, 도장), 라인을 고르면 공정별 OEE [가정]
  - 주·월 조회 시 일별 OEE 추이
  - 비가동 코드별 시간·건수
  - 상태 타임라인 (00:00~24:00, 라인·공정 또는 설비별 R/S/I/D 구간)
- 예외: 부하시간이 0이면(자정 직후, 하루 전체가 계획정지인 날) 값 대신 "-" 표시

### FN-005 이상 감지·알림
- 트리거: 설비 상태가 D로 바뀔 때 (장비고장, 장비고장(알람), 안전문제)
- 처리:
  1. 알람 기록 생성 (FN-006과 같은 건)
  2. 화면: 토스트 표시, 헤더 알림 개수 증가
  3. 이메일 발송(1순위), 이어서 슬랙 발송(2순위). 수신자와 슬랙 웹훅은 설정 파일 고정값
  4. 같은 설비의 같은 알람은 해제 전까지 다시 보내지 않음
- 출력: 토스트, 헤더 알림 목록(최근 5건), 이메일·슬랙 메시지 (라인, 설비, 상태, 코드, 상세, 발생 시각, 화면 링크)
- 예외: 이메일·슬랙 발송이 실패해도 화면 알림은 그대로 유지하고 실패를 기록

### FN-006 비가동 이력 관리
- 입력: FN-002의 상태 변화
- 처리: 설비 상태가 R이 아닌 구간마다 1건 기록 (시작, 종료, 라인, 설비, 상태, 비가동 코드, 상세, 지속시간). 종료 전에는 "진행 중"
- 조회 필터 순서: 기간 → 라인 → 공정 → 상태 → 코드 → 진행 중만. 기본은 오늘·D·I(S는 선택 시 표시), 최대 31일, 50건씩 페이지
- 조치 메모: 건마다 한 줄, 선택 입력, 수정 가능. 저장한 로그인 사용자 이름을 조치 담당자로 자동 기록, 수정하면 마지막 저장자로 바뀜
- 출력: 이력 표(이메일·슬랙 발송 결과 열, 조치 담당자 열 포함), 계획수정 보고서 링크(D 상태 건)
- 예지보전 위험(90%) 기록은 같은 화면의 별도 탭에 표시

### FN-007 예지보전
- 대상: 관리값이 있는 설비 (슬리팅 전류·토크, 프레스 압력, 용접 전류·전압, 도장 pH·온도)
- 처리:
  1. 항목별 위험도(%) = 최근 10분 평균값이 기준 범위 가운데에서 상한(또는 하한)까지 간 비율
  2. 설비 위험도 = 항목 중 가장 높은 값, 그 항목명을 함께 표시
  3. 80% 이상 주의, 90% 이상 위험. 기준은 FN-015 값
- 출력: 위험 순 설비 목록(관리값 있는 38대, 정상은 접어둠, 설비명에 라인 표시 예: L3 프레스 2단), 선택 설비의 관리값 추이 차트 (상·하한선과 80%·90%선)
- 알림: 위험(90%)이 되면 대시보드 알림 열에만 표시. 이메일·슬랙은 보내지 않음
- [차순위] 값이 변하는 속도로 "상한 도달 예상 시간" 표시
- 제외: 정비 이력

### FN-008 생산 데이터 분석·리포트
- 입력: FN-003, FN-004, FN-006, FN-017 결과
- 처리:
  - 라인별·공정별 생산량과 공정별 불량 수
  - 비가동 코드별 시간·건수
  - 재공품 = 앞 공정 양품 − 뒤 공정 투입, 공정 사이마다
  - OEE 요약
- 출력: 날짜별 일일 생산 리포트 화면 (하루 요약, PDF 없음). 제품별 상세는 FN-018

### FN-009 생산 재배정·계획수정 보고서
- 트리거: 자동 생성하지 않음. 사용자가 D 상태 건(대시보드 알림 열, 이력 화면)에서 [보고서 만들기]를 누르면 그 시점 기준으로 계산
- 재배정은 제안만 하고 목표·설비 계획을 실제로 바꾸지 않음
- 규칙:
  1. 라인 L1~L6 안 설비 고장 → 직렬이라 그 라인 전체가 멈춘 것으로 봄. 부족 수량 = 그 라인이 오늘 남은 시간(자정까지) 동안 만들 예정이던 라인 계획 수량
  2. 다른 정상 라인 각각의 남은 능력 = 남은 시간 ÷ 라인 CT − 남은 라인 계획
  3. 부족 수량을 남은 능력 비율대로 나눠 배정
  4. 남은 능력 합이 부족 수량보다 적으면 "목표 미달 예상 ○개" 표시
  5. 도장 설비 고장 → 같은 공정의 다른 1대로 같은 계산. 비전은 1대라 대체 없음 → 출고 전량 미달 예상 [가정]
- 출력: 정해진 문장 틀로 작성한 보고서 (발생 라인·설비·시각·원인, 부족 수량, 라인별 추가 배정 표, 결과). 화면 조회 + PDF 다운로드. 날짜별 보고서 목록
- 예외: 정상 라인(또는 같은 공정 다른 설비)이 없으면 전량을 미달 예상으로 표시

### FN-010 3D 공장 모니터링
- 위치: 별도 메뉴 없이 대시보드 공정 흐름 영역에서 2D ↔ 3D 전환
- 처리: 3D 공장 모델의 설비마다 RSID 상태를 색으로 표시, 1초 갱신
- 출력: 3D 화면, 알람 패널(현재 D 상태 설비), 설비 클릭 시 정보 패널(설비 ID, 상태, 코드, 관리값 현재값, 공정상세 바로가기)
- 나중에 새로 설계

### FN-011 미세정지 감지 (차순위)
- 입력: 설비별 사이클 완료 이벤트(실제 CT), 슬리팅은 지령 주파수와 출력 주파수
- 처리:
  - 상태가 R인 채로 실제 CT가 표준CT × 1.5를 넘으면 미세정지 1건
  - 손실시간 = 실제 CT − 표준CT
  - 슬리팅은 출력 주파수가 지령 주파수보다 일정 비율 이상 낮은 구간을 미세정지로 봄 [가정]
- 출력: 설비별 미세정지 건수·손실시간, 사이클타임 분포. 손실은 성능가동률에 반영됨(3.3)
- 시뮬레이터가 지연을 일부러 넣어 검증 (FN-012)

### FN-012 데이터 시뮬레이터
- 역할: 시각·상태가 없는 데이터셋을 실시간 설비 데이터처럼 만들어 보냄
- 처리:
  1. 데이터셋 행을 사이클마다 하나씩 재생하고 현재 시각을 붙임
  2. 1대분 데이터를 노이즈·오프셋으로 복제해 설비 대수를 맞춤 (프레스 24, 용접 6 등)
  3. 슬리팅 투입 때 제품 ID를 발급하고, 제품이 라인 안 설비를 차례로 거쳐 비어 있는 도장 설비 → 출고로 가게 함
  4. 공정 사이 버퍼를 흉내 내 앞뒤 영향(재공부족, 작업지연)이 생기게 함
  5. 공정 B~E 끝에서 검사 판정을 만듦: 그 사이클 관리값이 기준을 벗어났으면 불량, 아니면 공정별 기본 불량률 0.5%로 무작위 [가정]
  6. 계획정지 일정(예방보전, 금형 교체, 코일·나이프 교체)을 만들고, 같은 일정을 백엔드 근무 캘린더에 넣음. 화면 입력은 없음
  7. 시나리오(고장, 관리값 이탈, 미세정지 지연)를 넣음
  8. 결과를 OPC UA로 Node-RED에 보냄
- 조작: 특정 설비에 고장을 즉시 넣는 기능. 별도 화면 없이 명령으로 실행

### FN-013 품질 현황
- 입력: 공정 검사 결과(FN-017), 출고 비전검사기 제품별 판정 (양품 1 / 불량 0)
- 처리: 오늘 공정별 불량 수, 출고 양품·불량 수, 불량률 = 불량 / 검사 수. 라인별로도 집계
- 출력: 대시보드 "품질" 칸(공정별 불량 수 + 출고 양품·불량·불량률, 원형 그래프) [가정]. 양품 수는 FN-003 실적과 FN-004 양품률에 쓰임

### FN-014 생산 목표 입력
- 입력: 날짜, 공장 목표 수량 (하루 1건)
- 처리: 같은 날짜는 덮어씀. 오늘과 미래 날짜만 입력·수정, 지난 날짜는 잠금. 저장하면 FN-003 달성률과 라인 계획(목표 ÷ 가동 라인 수)에 바로 반영
- 예외: 목표가 없는 날은 전날 값을 가져오지 않고 "목표 미설정" 표시
- 출력: 최근 목표 목록과 날짜별 달성률

### FN-015 관리값 기준 설정
- 입력: 설비 종류, 관리값 항목별 하한·상한
- 처리: 저장하면 바로 FN-002 판정 3번과 FN-007 위험도에 반영
- 기본값: 데이터셋 설명서의 정상 범위 (예: 프레스 Pressure 1·2 200~350, 합계 400~700)
- 출력: 항목마다 마지막 수정 시각·수정자 (변경 이력 목록은 없음)
- 예외: 하한이 상한보다 크면 저장하지 않고 오류 표시

### FN-016 로그인
- 입력: 아이디, 비밀번호
- 처리: 로그인하지 않은 채 다른 화면에 들어오면 로그인 화면으로 보냄. 로그인 후 원래 가려던 화면으로 이동
- 출력: 로그인 성공 시 대시보드, 실패 시 "아이디 또는 비밀번호가 맞지 않습니다"
- 로그인 유지: 자동 로그아웃 없음. 브라우저를 닫아도 7일간 유지
- 실패 횟수에 따른 계정 잠금 없음
- 로그아웃: 헤더 사용자 메뉴

### FN-017 공정 검사·불량 제외
- 위치: B 슬리팅, C 프레스(4단 끝난 뒤 1회), D 용접, E 도장 끝. F 출고 비전검사가 최종 검사 (FN-013) [가정]
- 검사는 별도 설비가 아니며 RSID 상태가 없다 [가정]
- 입력: 시뮬레이터 검사 판정 (제품 ID, 공정, 설비, 시각, 판정, 불량 사유) [가정]
- 처리:
  1. 판정을 제품 이력에 기록
  2. 불량이면 그 제품을 제외(폐기)하고 다음 공정에 넣지 않음. 재작업 없음 [가정]
  3. 공정 양품·불량 수를 집계해 FN-003 생산량, FN-004 양품률, FN-008 재공품, FN-013 품질에 전달
- 출력: 공정별 오늘 검사 수·불량 수·불량률, 불량 목록(시각, 제품 ID, 설비, 사유)
- 불량은 알림을 보내지 않음 [가정]

### FN-018 생산 조회
- 입력: 조회 조건 — 기간(일 / 주 / 월 또는 날짜 범위, 최대 31일) [가정], 라인(전체 / L1~L6), 결과(전체 / 양품 출고 / 불량 제외 / 진행 중), 제품 ID 검색
- 처리:
  - 기간·라인별 투입, 공장(라인) 실적, 계획, 달성률, 공정별 불량 제외 수
  - 라인별 계획 대비 실적
  - 일 조회: 시간대별 누적 실적 vs 계획선. 주·월 조회: 일별 실적 vs 계획
  - 제품 내역: 제품 ID, 라인, 투입 시각, 완료 시각, 거친 공정, 결과(양품 / 어느 공정에서 불량 제외 / 진행 중)
  - 제품 하나를 펼치면 공정별 설비·통과 시각·검사 판정·불량 사유
- 출력: 요약 숫자, 라인별 막대, 기간 추이 그래프, 제품 내역 표(50건씩 페이지)
- 예외: 제품 단위 기록은 90일 보존. 그보다 지난 기간은 수량 집계만 보이고 제품 내역은 "데이터 없음"
- 진입: 메뉴 "생산", 대시보드 "오늘 생산" 칸 클릭(기간 = 오늘)
