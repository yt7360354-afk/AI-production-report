## 1. 공통
- 대상 기기/해상도: 사무실 PC 모니터 (D-37), 1920×1080 기준 [가정]
- 실시간 갱신: 1초 (D-38)
- 3D: 대시보드에서 2D ↔ 3D 전환, 별도 메뉴 없음 (D-39)
- 공통 레이아웃(헤더·메뉴): 헤더 = 로고 · 메뉴(대시보드 / 생산 / 가동률 / 예지보전 / 알람이력 / 리포트 / 설정) · 🔔 알림 · 사용자 메뉴(로그아웃)
- 라인 선택은 헤더에 두지 않음. 공장 1개, 라인은 화면 안에서 고름 (D-79)
- 설비 이름 표기: 라인 + 공정 + 번호. 예: L3 슬리팅, L3 프레스 2단, L3 용접, 도장 #1, 비전
- 화면 단계 (D-82): 메인(SCR-001) → 라인 상세(SCR-010) → 공정 상세(SCR-002). 화면 위에 이동 경로 표시 (예: 대시보드 > L3 > 프레스)
- 상태 색상 규칙 (D-77):

| 상태 | 색 |
|---|---|
| R 가동 | 초록 |
| S 정지 | 회색 |
| I 대기 | 노랑 |
| D 고장·알람 | 빨강 |
| 예지보전 주의 / 위험 | 노랑 테두리 / 빨강 테두리 |

- 빈 데이터 표시 (D-78): 숫자는 "-", 그래프·목록은 "데이터 없음". 통신 두절 상태는 없음 (D-19)

## 3. 화면 상세

### SCR-001 메인 대시보드
- 목적: 공장 전체의 지금 상태, 물류 흐름, 오늘 생산, 진행 중 이상을 한 화면에서 파악한다.
- 레이아웃: 왼쪽 본문(공장 배치도 → 생산·OEE·품질 3칸) + **오른쪽 세로 열 전체 = 알림** (D-46). 와이어프레임 `#s001`.
- 공장 배치도 (D-81): 설비 하나 = 칸 하나. 왼쪽에서 오른쪽으로

```
          ┌ L1 [슬리팅]─[프1][프2][프3][프4]─[용접] ┐
          ├ L2 [ ]─[ ][ ][ ][ ]─[ ]               ┤── [도장#1] ──┐
 [입고] ──┼ L3 …                                  ┤               ├── [비전] (출고)
          ├ L4 …                                  ┤── [도장#2] ──┘
          ├ L5 …                                  ┤
          └ L6 …                                  ┘
```

|---|---|---|---|---|
| 1 | 공장 배치도 | 배치도 | 현재 상태 ③, DT-003 | 입고 1칸 · 라인 6줄(슬리팅 1 · 프레스 4 · 용접 1) · 도장 2칸 · 비전 1칸(출고, D-90). 칸 색 = 설비 상태(D-77). 칸 안에 상태 코드, D면 지속시간 |

### SCR-010 라인 상세
- 목적: 한 라인의 설비 흐름, 생산 계획 대비 실적, 불량, 멈춘 곳을 본다.
- 레이아웃: 이동 경로 + 라인 탭(L1~L6, 도장) → 라인 요약 4칸 → 라인 흐름(설비 칸) → 시간대별 라인 생산 그래프 + 라인 오늘 알림. 와이어프레임 `#s010`.

| No | 항목 | 유형 | 데이터 출처 | 표시 규칙 |
|---|---|---|---|---|
| 1 | 라인 탭 | 탭 | DT-001 | L1~L6, 도장. 대시보드에서 누른 라인이 선택됨 |
| 2 | 라인 요약 | 숫자 4칸 | 현재 상태 ③, DT-017, DT-018 | 라인 대표 상태(D>I>S>R)와 RSID 대수, 오늘 라인 실적 / 라인 계획 / 달성률 (D-87), 라인 OEE, 오늘 불량 제외 수 |
| 3 | 라인 흐름 | 설비 칸 + 선 | 현재 상태 ③, DT-003, DT-011 | L1~L6: 슬리팅 → 프레스 1~4단 → 용접. 도장: 도장 #1 · #2. 칸 = 상태 색 + 코드 + 지속시간. 공정 묶음 위에 공정 이름, 공정 사이에 재공·오늘 생산·불량 수. 물류 점은 SCR-001과 같음 |
| 4 | 시간대별 라인 생산 | 선 그래프 | DT-018 | 00:00~24:00, 라인 계획선 vs 라인 누적 실적 |
| 5 | 라인 오늘 알림 | 목록 | DT-013 | 이 라인 설비의 오늘 비가동·알람, 진행 중 위 |

| 이벤트 | 동작 | 결과 |
|---|---|---|
| 공정 이름(묶음) 클릭 | 이동 | 그 공정 상세(SCR-002-2~5), 첫 설비 선택 |
| 설비 칸 클릭 | 이동 | 그 공정 상세, 그 설비 선택 |
| 라인 탭 변경 | 전환 | 다른 라인으로 |
| 알림 클릭 | 이동 | 해당 공정 상세, 해당 설비 |

### SCR-002 공정 상세 — 공통 틀
- 목적: 한 라인 안 한 공정의 설비별 상태, 관리값, 검사 불량, 비가동 이력을 보고 원인을 파악한다.
- 공정마다 화면을 따로 둔다: SCR-002-1 코일입고 · 002-2 슬리팅 · 002-3 프레스 · 002-4 용접 · 002-5 도장 · 002-6 출고 (D-89). 아래는 002-2~5가 함께 쓰는 틀이고, 공정별 화면은 이 틀에서 다른 점만 적는다.
- 레이아웃: 이동 경로(대시보드 > L3 > 프레스) + 공정 탭 → 공정 요약 4칸 → 설비 목록 → 선택 설비의 관리값 그래프 + 비가동 이력·조치 메모 → 공정 검사 → 미세정지. 와이어프레임 `#s002`.
- 공정 탭: L1~L6은 [슬리팅 / 프레스 / 용접] (002-2~4 사이 이동), 도장 라인은 [도장] 하나. 입고·출고는 탭 없이 단독 (D-82)

| No | 항목 | 유형 | 데이터 출처 | 표시 규칙 |
|---|---|---|---|---|
